# BodySync v1.1

Mobile-first PWA für Ernährung, Gewicht und persönliche Ziele.

## Neu in v1.1

- Mahlzeiten: Frühstück, Mittagessen, Abendessen und Snacks
- Kohlenhydrate und Fett zusätzlich zu Kalorien und Protein
- Favoriten-Markierung und Favoritenfilter
- Suche in den Einträgen des ausgewählten Tages
- Gruppierte Tagesansicht nach Mahlzeiten
- Automatische Migration von `bodysync-data-v5` auf `bodysync-data-v6`
- JavaScript-Modulstruktur unter `js/`

## Deployment

Alle Dateien vollständig ersetzen, committen und zu GitHub pushen. Vercel kann das Projekt weiterhin als statische Website ausliefern.
